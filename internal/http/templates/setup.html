IDPico is running, but nobody can sign in until a user exists. Pick one:

A file next to the binary

Create .env in the directory you start idpico from, then restart it:

IDPICO_BOOTSTRAP_USERS={{.Email}}:change-me:Your Name
IDPICO_ADMIN_EMAILS={{.Email}}
IDPICO_BOOTSTRAP_CLIENTS=my-app|my-app-secret|http://localhost:3000/callback

One line each for the first user (who gets the admin console), and your application as an OIDC client with its redirect URI. The same three lines work as environment variables, in docker compose or in a Kubernetes manifest.

Or the command line

idpicoctl user add {{.Email}} -admin
idpicoctl client add my-app -redirect http://localhost:3000/callback

Both print what they created; client add shows the secret once. No restart needed.
